ProjectedSumOfTents ​

python
ProjectedSumOfTents(points, half_widths, normal, weights=None, target_mass=1.0, proj_dims=2, **kwargs)

1D TENTS that are the projections of shared points on a direction per item of a batch -- e.g. one per angle of a tomography: points [ n, proj_dim ], half_widths [ n ], weights [ n ] the masses, normal [ proj_dim ] per item. A continuous distribution: its transport against an Image ( ContinuousOtPlan1d ) is differentiable, with no kink when two tents cross -- what diracs lack.

ProjectedSumOfAnisotropicTents ​

python
ProjectedSumOfAnisotropicTents(points, matrices, normal, weights=None, target_mass=1.0, proj_dims=2, **kwargs)

1D TENTS of different widths at different directions: the projections of ELLIPTIC objects. Like ProjectedSumOfTents, with a matrix matrices[ i ] [ proj_dim, proj_dim ] per tent instead of a half-width: tent i on the line of direction normal is centered at s_i = points_i . normal, with the half-width w_i = | matrices_i^T normal |, so that an isotropic tent is matrices_i = w_i * identity. It is what an object whose shape is the image of a disk by matrices_i projects to ( a transformed disk is an ellipse ). Differentiable with respect to points and matrices, through ContinuousOtPlan1d ( the exact method, on the host ). ProjectedSumOfTents is faster when all the tents are round.

Image ​

python
Image(values=None, frame=None, pixel_frame=None, target_mass=1.0, degree=0, **kwargs)

Piecewise function on a grid: a constant per pixel ( degree = 0 ), or a polynomial of degree degree along each axis.

degree = P > 0: values is [ pixels..., ( P + 1 )^d ], the BERNSTEIN coefficients of each pixel, in its own coordinates t in [ 0, 1 ]^d, flattened in C order ( the first axis the slowest ): rho = sum_alpha c_alpha prod_a B_{ alpha_a, P }( t_a ). Coefficients >= 0 give a density >= 0, and the mass of a pixel is its volume times the mean of its coefficients. They are stored in the field coeffs ( values stays unset ).

Each square/cube/hypercube is defined by origin and frame( dir ) * knots( ... ): the FIELD frame is the frame of ONE pixel ( its rows: the edges of a pixel ).

By default, knots is equal to 0, 1, ... for each dim.

What the constructor takes is said for the WHOLE image: Image( values ) fits the image in the unit square ( cube... ) at origin, its longest side of length 1, the proportions kept. frame gives the edges of the whole image ( rows, or their lengths for an axis-aligned image ), pixel_frame those of one pixel ( the field ). With knots, the pixels are where the knots say: the default frame is the identity.

SplineGrid ​

python
SplineGrid(values, degree=3, frame=None, pixel_frame=None, origin=None, interpolate=False, target_mass=1.0)

A smooth density on a grid of pixels: the tensor-product B-spline of degree degree ( C^{ degree - 1 } ) whose control coefficients are values, one per pixel, at its center. Non-negative values give a non-negative density. The grid is placed like that of an Image ( frame, pixel_frame, origin ), and the density is zero outside it.

interpolate = True: values are SAMPLES at the centers of the pixels instead, and the coefficients are those of the spline that goes through them. Such a spline can dip below zero near a sharp edge: it is then refused ( a ValueError ), and a lower degree, or interpolate = False, keeps it non-negative.

It is an Image( degree = degree ): each span of the spline is a polynomial, written in the Bernstein basis of its pixel. Differentiable with respect to values.

SumOfGaussians ​

python
SumOfGaussians(positions, sigmas, weights=None, target_mass=1.0, support_sigmas=6.0, support_box=None, **kwargs)

A mixture of isotropic gaussians: positions [ k, d ] their centers, sigmas [ k ] their standard deviations, weights [ k ] their masses ( not their heights; equal by default ). Differentiable with respect to all three.

Its support, which bounds the domain of a transport, is the box holding every gaussian up to support_sigmas standard deviations ( 6 by default ), or the box support_box = ( lo, hi ).

Mesh ​

python
Mesh(nodes, simplices, values=None, target_mass=1.0, degree=1, **kwargs)

A piecewise linear density on a mesh of simplices ( triangles in 2D, tetrahedra in 3D ), zero outside.

nodes [ nb_nodes, d ], simplices [ nb_simplices, d + 1 ] ( indices of nodes ). values: [ nb_nodes ] for a continuous density ( one value per node ), or [ nb_simplices, d + 1 ] for a density discontinuous between simplices ( one value per corner of each simplex: zeros make a hole ). Constant by default. Differentiable with respect to values. degree = 0: a density CONSTANT on each simplex, the mean of its corner values ( what partial transport takes in 3D: PowerDiagram( sink_weight = ... ) ).

.from_contours(contours, box=None, mesh_size=0.05, inside=1.0, outside=0.0, margin=0.2) ​

a 2D mesh generated by pygmsh ( needs it installed ) from closed CONTOURS: contours is a list of [ n, 2 ] arrays of points ( in order, not repeated at the end ), each one the border of a region. The regions are paved with triangles, together with a box around them, whose edges follow the contours ( no triangle straddles one ). The density is inside ( 1 ) on the triangles within a contour and outside ( 0 ) on those of the box around.

CodimMesh ​

python
CodimMesh(nodes, simplices, values=None, width=None, target_mass=1.0, alpha=15.0, margin=0.25, quadrature=False, smoothed=False, **kwargs)

A measure carried by a mesh M of LOWER dimension: segments in 2D or 3D, triangles in 3D ( Mesh( nodes, simplices ) with fewer than d + 1 nodes per simplex gives one ). values is rho at the nodes of M ( P1, ones by default ): the measure is rho times the length ( area ) on M, and its cells are integrated exactly ( CodimMeasureDensity ).

THE WIDTH CONTINUATION of the solver goes through smoothed densities, rho exp( -d^2 / s^2 ), d the distance to M and rho its value at the closest point of M, integrated in closed form on the ENVELOPE of M ( sdot.envelope: the generalized Voronoi diagram of its elements, simplices where d and rho are affine, in the box of M widened by margin times its diagonal ), from wide down to width, and then the measure itself ( sdotplan/convolved/CodimMesh.h ). Default width: DEFAULT_WIDTH times the diagonal of M. smoothed = True gives the smoothed density at width instead of the measure ( a check, or a density of its own ).

alpha: the widest angle of the fans of the envelope, in degrees ( d is over-estimated by at most 1 / cos( alpha / 2 ) around the nodes, and the edges in 3D ). quadrature = True integrates the smoothed pieces by PointwiseDensity ( a check ).
