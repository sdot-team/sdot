Convex Polytopes ​

The simplest target: the Lebesgue measure on a convex polytope, a constant density inside and zero outside. Three ways to give the polytope:

python
target = sdot.ConvexHull( points )                      # points [ n, d ]: the convex hull of points, in any dimension
target = sdot.Polytope( directions, offsets )           # the half-spaces directions . x <= offsets ( [ m, d ], [ m ] )
target = sdot.Box( origin = None, frame = None )        # a box: the unit square ( cube ) by default

The polytope is also the domain of the transport: the cells start from it, and are cut by the planes of the power diagram. Nothing lies outside it, so no cell is unbounded.

ConvexHull ​

ConvexHull( points ) is the convex hull of points ( [ n, d ], in any order ): a polygon in 2D, a polyhedron in 3D. The points inside the hull are ignored, and a flat hull ( all the points in a hyperplane ) raises a ValueError.

300 diracs gathered in the middle of a heptagon, and their cells: first with zero weights ( the Voronoi diagram cut by the polygon ), then with the weights of the transport, where each cell holds 1/300 of the area ( the slider at the top switches between them ):

python
target = sdot.ConvexHull( vertices )                    # 7 vertices on an ellipse
p = sdot.plan( sdot.SumOfDiracs( x ), target )

Polytope ​

Polytope( directions, offsets, density = 1 ) is the intersection of the half-spaces ac⋅x≤bc. The directions need not be unit vectors: each row is normalized, with its offset. The polytope has to be bounded and non-empty ( it raises otherwise ), but a half-space may be redundant.

A regular nonagon cut by one more half-space, and the Lloyd quantization of its Lebesgue measure ( 2000 diracs, see Lloyd quantization ):

python
t = 2 * np.pi * np.arange( 9 ) / 9
directions = np.concatenate( [ np.stack( [ np.cos( t ), np.sin( t ) ], -1 ), [ [ 0.3, 1.0 ] ] ] )
offsets = np.r_[ np.full( 9, 0.5 ), 0.2 ]

x = sdot.quantization( sdot.Polytope( directions, offsets ), 2000, seed = 0 )

In 3D ​

Nothing changes but the dimension. An icosahedron from its 12 vertices, and 4000 diracs colored by their depth in the view ( warm in front; c switches it ):

python
phi = ( 1 + 5 ** 0.5 ) / 2
v = [ [ 0, s, t * phi ] for s in ( -1, 1 ) for t in ( -1, 1 ) ]
vertices = np.array( [ p[ k: ] + p[ :k ] for p in v for k in range( 3 ) ], dtype = float )

x = sdot.quantization( sdot.ConvexHull( vertices ), 4000, seed = 0 )

The cells of a transport from 60 random diracs to the unit cube cut by two oblique planes:

directions = np.concatenate( [ np.eye( 3 ), -np.eye( 3 ), [ [ 1, 1, 1 ], [ -1, 0.5, -1 ] ] ] )
offsets = np.r_[ np.ones( 3 ), np.zeros( 3 ), 2.4, -0.25 ]

p = sdot.plan( sdot.SumOfDiracs( x ), sdot.Polytope( directions, offsets ) )

Box ​

Box( origin = None, frame = None ) is the box origin + frame^T [ 0, 1 ]^d: the rows of frame are its edges, or frame is their lengths for an axis-aligned box. By default it is the unit square ( cube... ) in the dimension of the source: sdot.w2( f, sdot.Box() ) works for any f.

A box is an Image of one pixel. It is differentiable with respect to origin and frame.

What is computed ​

The density is constant, so every integral over a cell is a polynomial integral over a convex polytope: the masses, the barycenters, the transport cost and the facets of the Newton system are exact, with no quadrature. There is no width continuation either: the density is already as smooth as it gets, and the solver goes straight to Newton.

On the CUDA card, a polygon or a polyhedron with few enough facets, all of whose vertices are simple, is the cell every seed starts from; anything else starts from the box of its vertices, cut by its facets. The result is the same.

A constant density on a polytope also works with a periodicity ( 2D and 3D, on the card too for translations ) and with partial transport ( 2D, on the CPU ).

Reproducing the pages ​

They are written by docs/guide/distributions/polytope_figures.py:

bash
python docs/guide/distributions/polytope_figures.py                     # all of them
python docs/guide/distributions/polytope_figures.py plan icosahedron    # or some of them

Limits ​

  • Convex polytopes only. A non-convex domain is a union of convex ones, or an Image ( a mask ), or a Mesh of simplices.
  • The geometry ( points, directions, offsets ) is a constant of the transport: nothing differentiates through it. The density may be traced, but the target is normalized, so its derivative is zero. A Box is differentiable with respect to its origin and frame.
